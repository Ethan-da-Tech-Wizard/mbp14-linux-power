# Placeholders

Everything personal or specific to the original author's setup was removed from this repository and replaced by a
placeholder written in double curly braces. This page is generated by the build from the placeholders that actually exist in the files, so
every one found in the code is listed here with its meaning, what to do, and where it occurs. Search the repository
for `{{` to find them all. None of them is needed for the system files or the power policy to work: they sit in
comments and documentation strings, not in values the programs read.
